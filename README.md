Retail Sales Analysis Using Excel
## Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel to identify sales trends, profit performance, and regional performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- SUMIF
- Charts and Data Visualization
- Excel Formulas

## Key Analysis

- Category-wise Sales Analysis
- Category-wise Profit Analysis
- Region-wise Sales Analysis
- Region-wise Profit Analysis
- Total Sales, Total Profit, Total Orders, and Total Customers

## Key Business Insights

1. South Region has the highest sales.
2. Electronics is the top-selling category.
3. Total Sales: ₹1,64,10,832.

- Data Analysis
- Data Cleaning
- Data Visualization
- Dashboard Creation
- Business Insights
